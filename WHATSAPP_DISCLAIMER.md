# WhatsApp Integration Disclaimer

**Evolution API is a third-party / unofficial WhatsApp integration layer and is NOT the official WhatsApp Cloud API.**

- Use Evolution API only for controlled development/demo use.
- Using unofficial gateways may violate WhatsApp's Terms of Service and can result in the number being banned.
- Do **not** implement or use this system for spam, bulk messaging, unsolicited messaging, scraping, or mass outreach.

**For production, use the official Meta WhatsApp Business Platform (Meta Cloud API).** This application's provider abstraction is explicitly designed so you can switch from Evolution API to the Meta Official API per-restaurant with no changes to the ordering engine.
